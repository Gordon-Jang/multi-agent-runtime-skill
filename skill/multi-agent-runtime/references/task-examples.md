# Task Examples

Use these examples to shape concise goals for `run-team.ps1`.

## Code Review

```powershell
.\run-team.ps1 -Goal "Review this project for bugs, security issues, and missing tests. Return findings first with file references when possible."
```

## Implementation Planning

```powershell
.\run-team.ps1 -Goal "Plan the smallest implementation for adding user profiles. Include changed files, risks, and verification steps."
```

## Test Planning

```powershell
.\run-team.ps1 -Goal "Create a practical test plan for this project, prioritizing fast local checks."
```

## Cross-Project Use

```powershell
.\run-team.ps1 -Goal "Inspect this repo and summarize architecture risks." -Workspace "D:\path\to\project"
```
